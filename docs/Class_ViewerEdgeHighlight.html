ViewerEdgeHighlight

Three.js overlay that draws prepared edge highlights as thick screen-space lines. WebGL lines are always one pixel wide, so the polylines are drawn as quads with a width in CSS pixels. LineSegments2 sets the material's resolution from the viewport before every render.

new ViewerEdgeHighlight ()

Methods

GetMeshPolygonOffsetFactor ()
Description
The polygon offset factor the meshes need so that no wall next to a line covers it. A wall rises toward the camera by its depth slope per pixel, at most sqrt (2) times the slope the polygon offset uses, over the line's half width. One more for rasterization.
