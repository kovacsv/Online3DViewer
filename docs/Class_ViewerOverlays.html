ViewerOverlays

Draws the surface strain and the edge highlights of a model on a Viewer. It is shared by EmbeddedViewer and the website, see their methods with the same names for details.

Constructor

new ViewerOverlays (viewer)
Parameters
viewer Viewer
The viewer to draw on.

Methods

SetModel (model)
Description
Sets the model the overlays belong to. It must be called with null when a new model starts loading and with the model when it is shown. The viewer is cleared by its owner.
Parameters
model Model
The shown model or null.
HasModel ()
Returns
boolean True if a model is set.
